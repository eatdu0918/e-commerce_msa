# e-commerce msa 최종 프로젝트  

### MVP (Minimum Viable Product) 정의

#### 핵심 기능(Must Have)
1. 사용자 관리 (Step 1)
   *  회원가입/로그인 (JWT 인증)
   *  기본 프로필 관리
   *  권한 관리 (USER/ADMIN)
2. 상품 관리(Step 2) 
   *  상품 CRUD
   *  카테고리 관리
   *  재고 관리 기본 기능
   *  상품 검색 (기본)
3. 주문 처리 (Step 3)
   *  장바구니 기능
   *  주문 생성
   *  주문 상태 관리
   *  재고 차감 연동

#### 주요기능(Should Have)
 * Mock 결제/배송 관리/알림/ 등
